= Issues Browser

Local forge issues and discussions browser. Syncs into per-repo SQLite for offline archive/browse.

link:https://docs.devcentr.org/issues-browser/[Explore the docs] ·
link:https://github.com/dev-centr/issues-browser/issues[Report Bug] ·
link:https://github.com/dev-centr/issues-browser/issues[Request Feature]
endif::[]

== About The Project

Offline archive/browser for forge **issues and discussions** (renamed from _issue-tracker_).
Data lives at `<repo>/.issues/database.sqlite`; sync ensures `.issues/` is gitignored.
Large repos and busy forks require explicit approval before syncing.

* **Recursive git discovery** and `**/.issues/database.sqlite` archive discovery
* **Per-repo SQLite** inside the repo (not a shared username `.issues` tree)
* **Discussions** synced by default; PRs excluded unless `--include-prs`
* **GUI + CLI + library**

Bodies stay in SQLite; guardrails address sync volume, not DB body size.

== Installation

=== Requirements

* **gh** CLI authenticated for API access.
* **SQLite**: see link:docs/modules/ROOT/pages/installation.adoc[Installation].

=== Build

[source,bash]
----
dub build --config=cli
dub build --config=application
----

== Usage

[source,bash]
----
issues-browser --add-folder /path/to/code
issues-browser --sync /path/to/repo
issues-browser --sync /path/to/busy-fork --yes
issues-browser --list /path/to/repo --search "antora"
issues-browser --find-db /path/to/code
----

Full docs: https://docs.devcentr.org/issues-browser/
