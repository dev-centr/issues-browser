= Issues Browser

Local forge issues and discussions browser. Archives threads into per-repo SQLite for offline browse and search.

link:https://docs.devcentr.org/issues-browser/[Explore the docs] ·

link:https://github.com/dev-centr/issues-browser/issues[Request Feature]
endif::[]

== About The Project

Issues Browser is an *offline archive and browser* for forge issues and discussions (not a place to file new tickets). Sync pulls remote threads into SQLite so you keep a local copy if the host or upstream repo disappears.

* **Recursive git discovery**: Add a folder; the app finds repos (directories containing `.git`).
* **Per-repo archive**: `<repo>/.issues/database.sqlite` inside the repo (gitignored automatically).
* **Issues + discussions**: GitHub Discussions sync on by default; PRs excluded unless requested.
* **Sync guardrails**: Preflight counts; warn/confirm on large repos and busy forks.
* **GUI (DlangUI)** and **CLI** over the same library API.

This is separate from the personal **issue-submissions** catalogue (`AMDphreak/.issue-submissions`), which stores draft/submitted issue markdown and screenshots for AI-assisted `gh` workflows.

== Installation

=== Requirements

* **gh** CLI authenticated for GitHub API / GraphQL access.
* **SQLite**: On Windows, use the bundled d2sqlite3 `all-included` config (default here) or provide `sqlite3.lib`.

=== Build

[source,bash]
----
dub build --config=cli
dub build --config=application   # GUI (requires dlangui)
dub build --config=library
----

== Usage

=== Quick start

. Add a folder that contains git repos (e.g. your `code/github.com/dev-centr`).
. Sync: fetches issues and discussions into `<repo>/.issues/database.sqlite` (adds `.issues/` to that repo's `.gitignore`).
. Browse and search in the GUI or via CLI.

CLI examples:

[source,bash]
----
issues-browser --add-folder Z:\code\github.com\dev-centr
issues-browser --find-dbs Z:\code\github.com\dev-centr
issues-browser --sync Z:\code\github.com\dev-centr\issues-browser
issues-browser --sync Z:\code\github.com\.clones\npm\cli --yes
issues-browser --list Z:\code\github.com\dev-centr\issues-browser --search "antora"
----

Large repos and forks prompt for confirmation unless you pass `--yes`.
