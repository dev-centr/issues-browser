= Issues Browser

Local **forge metadata backup** for issues, pull requests, and discussions. Archives into central SQLite under `AMDphreak/.issues/archives`; browse offline via GUI/CLI; monitor continuously with `issuesd` + tray.

link:https://docs.devcentr.org/issues-browser/[Docs] ·
link:https://github.com/dev-centr/issues-browser/issues[Issues]

== Components

* **Library** — sync engine, SDL forge profiles, SQLite schema, monitor store
* **CLI** (`issues-browser`) — ProHelp (`openshellorg/prohelp`, PCDL) + sync/list/monitor
* **GUI** (`issues-browser-gui`) — DlangUI browser
* **Daemon** (`issuesd`) — incremental polling + localhost IPC `:17365`
* **Tray** (`issues-browser-tray`) — Win32 tray client for the daemon

== Quick start

[source,bash]
----
dub build --config=cli
issues-browser --sync ./myrepo --yes
issues-browser --monitor-add owner/name
dub build --config=daemon && issuesd
dub build --config=tray && issues-browser-tray
----

Archives default to `$CODE_ROOT/github.com/AMDphreak/.issues/archives/<host>/<owner>/<repo>/database.sqlite`.
