= Installation

== Requirements

* **gh** CLI authenticated for GitHub API access (`gh auth login`).
* **SQLite**: The project uses the d2sqlite3 D binding. On Windows, the default configuration may expect `sqlite3.lib` on your library path. You can:
** Install SQLite (e.g. from https://sqlite.org/download.html) and add the lib path to your environment, or
** Use the `all-included` subConfiguration for d2sqlite3 (see Build).

== Build

[source,bash]
----
dub build --config=cli
dub build --config=application   # GUI (requires dlangui)
dub build --config=library       # library only
----

On Windows, this repo vendors `vendor/sqlite/win64/sqlite3.lib` (+ DLL) and wires `/LIBPATH` in `dub.json` for the CLI/GUI configs. `sqlite3.dll` is copied beside the executable on build.

[source,bash]
----
dub build --config=cli
----

CLI target name: `issues-browser`. GUI target name: `issues-browser-gui`.

== Notes

This project was renamed from `issue-tracker` to `issues-browser` to match its role as an offline archive/browser (not a submission tracker).
Issue draft/screenshot submissions for AI/`gh` workflows live in a separate user repo: `AMDphreak/.issue-submissions`.
