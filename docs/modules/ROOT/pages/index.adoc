= Issue Tracker

Issue Tracker is a local GitHub issues and comments browser. It syncs issues and their comment threads into a SQLite database stored in a `.issues` folder next to your repos, so you can browse and search them like a local copy of the GitHub issues tracker.

== Features

* Recursive git discovery: add a folder and the app finds all git repos (any directory containing `.git`).
* Per-repo SQLite: each repo gets `.issues/<reponame>.sqlite` next to the repo folder.
* GUI (DlangUI): browse repos, list issues, view body and comments, search, trigger sync.
* CLI: same sync and query from the command line.
* Library: use the core sync and database API from other D code.

== Requirements

* **gh** CLI (GitHub) must be installed and authenticated.
* SQLite: see xref:installation.adoc[Installation] for platform notes.

== Quick start

. Run the GUI or CLI and add a folder that contains git repos.
. Sync: the app uses `gh api` to fetch issues and comments into `.issues/<reponame>.sqlite`.
. Browse and search in the GUI or with the CLI.

See xref:usage.adoc[Usage] for CLI examples and GUI workflow.
