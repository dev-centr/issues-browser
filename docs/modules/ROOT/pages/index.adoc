= Issues Browser

Issues Browser is a local forge *issues and discussions* browser. It archives issue threads and GitHub Discussions into a SQLite database at `<repo>/.issues/database.sqlite`, so you can browse and search offline — useful when a remote repo or provider is unavailable.

It is an archive/browser, not a ticket tracker for filing new work. Personal draft/submit workflows live in a separate submissions catalogue (e.g. `AMDphreak/.issue-submissions`).

== Features

* Recursive git discovery: add a folder and the app finds git repos (any directory containing `.git`).
* Per-repo SQLite: `<repo>/.issues/database.sqlite` inside the repo; `.issues/` is added to that repo's `.gitignore`.
* Recursive archive discovery: find existing DBs via `**/.issues/database.sqlite` (does not treat a username-level `.issue-submissions` tree as an archive).
* Issues + discussions (discussions on by default); pull requests excluded unless `--include-prs`.
* Sync guardrails: GraphQL preflight counts; confirm before large or busy-fork syncs.
* GUI (DlangUI) and CLI over the same library.

== Requirements

* **gh** CLI (GitHub) installed and authenticated.
* SQLite: see xref:installation.adoc[Installation] for platform notes.

== Quick start

. Run the GUI or CLI and add a folder that contains git repos.
. Sync: the app fetches issues and discussions into `<repo>/.issues/database.sqlite`.
. Browse and search in the GUI or with the CLI.

See xref:usage.adoc[Usage] for CLI examples and GUI workflow.
